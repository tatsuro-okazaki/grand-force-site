Order Flow

ご注文からお届けまでの流れ

お問い合わせから納品まで、私たちは伴走者として一つひとつ丁寧に進行します。
初めての方にもわかりやすいよう、6つのステップでお届けまでをご案内します。

01

お問い合わせ

Inquiry

LINE・メール・お問い合わせフォームよりお気軽にご連絡ください。チーム名・人数・ご要望のアイテムなど、わかる範囲で構いません。

○所要：1分○方法：LINE / メール / フォーム
02

ヒアリング

Hearing

チームのコンセプト・着用シーン・ご予算・大会スケジュールなどを丁寧にお伺いします。アイテムイメージや参考画像があればご共有ください。

○所要：30〜60分○方法：オンライン / 対面 / チャット
03

お見積り

Estimate

ヒアリング内容をもとに、サイズ・数量・加工内容・納期を反映したお見積書をご提出します。複数パターンでのご提案も可能です。

○所要：1〜3営業日○無料お見積りシミュレーターもご利用可能
04

デザイン

Design

お見積りご承認後、専属デザイナーがデザイン制作に入ります。初稿提出後、ご納得いただけるまで修正対応いたします（規定回数あり）。

○所要：1〜2週間○修正：規定回数まで無料
05

生産

Production

デザイン最終確定後、生産工程に進みます。ホログラムやラインストーンなどの加工は、職人による手作業で一点一点仕上げます。

○所要：2〜4週間○進捗写真の共有も可能
06

納品

Delivery

検品後、ご指定の場所へ発送いたします。大会日程やイベントに合わせた納期調整もご相談ください。納品後のサイズ追加・再注文も対応可能です。

○発送：全国対応○追加注文・リピート歓迎

Craft Rules

ホログラム・ラインストーン
制作のルール

職人の手作業による特殊加工には、美しさと耐久性を両立するための制作ルールがあります。
仕上がりイメージとご相談時の参考にしていただけます。

※ 実際の規定・サイズ・最小単位は元情報を反映予定
Hologram

ホログラム加工

  • 最小サイズ細かいデザインは表現が難しい場合があります（例：5mm以下の文字は推奨外）。
  • カラーバリエーションシルバー / ゴールド / レインボー / ピンク / ブルー など。サンプル提示可能。
  • 推奨デザインシャープな形状・太めの線・大きめのモチーフが映えます。
  • 非推奨デザイングラデーション表現や極細ライン、複雑な曲線は再現が難しい場合があります。
  • 耐久性裏返し・ネット使用・手洗い推奨。アイロン直当てはNG。
※ 上記は一般的なガイドラインです。デザインによっては追加のご相談・サンプル制作をご提案する場合があります。
Rhinestone

ラインストーン加工

  • 最小発注個数ストーン使用デザインは100個以上での制作が目安となります。
  • サイズ展開SS6 / SS10 / SS16 / SS20 など複数サイズの組み合わせが可能。
  • カラーバリエーションクリスタル / AB加工 / カラーストーン（30色以上）から選択。
  • 配置ルール素材により貼り付け位置に制限があります（伸縮性のある部位、縫い目など）。
  • 耐久性・お手入れ裏返し・洗濯ネット使用・手洗い推奨。乾燥機・アイロンは厳禁。
※ ラインストーンは消耗品です。長期間の使用で一部脱落の可能性がありますが、リペア対応も承っております。

FAQ

よくあるご質問

Q.最小ロットはいくつから？+

アイテム・加工内容により異なりますが、ユニフォーム類は10着〜、グッズ類は20個〜が目安です。少量からのご相談もお気軽に。

Q.納期はどのくらい？+

ご発注確定後、約4〜6週間が目安です。大会スケジュールに合わせた調整もご相談いただけます。

Q.デザインの持ち込みはできますか？+

もちろん可能です。Illustratorデータはもちろん、手描きラフや参考画像からでもデザインを起こせます。

Q.追加注文はできますか？+

はい。新メンバー加入時のサイズ追加や、別カラーでのリピート制作も対応しています。

Q.支払い方法は？+

銀行振込・クレジットカード決済に対応しています。お支払い時期などの詳細はご相談時にご案内いたします。

Q.遠方でも依頼できますか？+

はい、オンラインでのヒアリング・打ち合わせに対応しております。全国どこからでもご依頼いただけます。
